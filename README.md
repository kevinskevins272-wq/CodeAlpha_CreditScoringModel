# Credit Scoring Model

## Project Overview

This project is a machine learning based Credit Scoring Model developed using Python.

The system analyzes customer financial information and predicts whether a customer is likely to default on a loan.

It also calculates a simple credit risk score and classifies the customer into LOW, MEDIUM, or HIGH risk.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- CSV Dataset
